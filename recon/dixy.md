# Дикси (dixy.ru) — разведка 2026-10-31

Сайт на 1С-Битрикс за Qrator. С russia-03 (дата-центр) отвечает 200, капчи нет.
Отдельного JSON API нет: фронт берёт данные из PHP-ручек `/ajax/*.php`. Каталог
полный (≈17 тыс. позиций по корням у дефолтной точки), а не только акции; цены и
ассортимент зависят от магазина. Playwright не нужен, хватает httpx.

## Заголовки и защита

```
User-Agent: <обычный браузерный UA>        # без него Qrator отдаёт 403 даже на HTML
Accept-Language: ru-RU
Referer: https://dixy.ru/
```

Сначала открываем `GET /catalog/`: сервер ставит `PHPSESSID` (и `gf_uid`, `DIXY2_SM_*`).
Выбранный магазин хранится **в PHP-сессии**: после `saveStore` хватает одного `PHPSESSID`.

Для `block=product-list` WAF пропускает запрос, только если в query есть
параметр `collect_stat` (можно пустой: `&collect_stat` или `&collect_stat=`).
Без него `403 Forbidden / Transaction ID`. Остальные ручки (`tree`, `filter-list`,
`facet-list`, `ajax.php`) работают и без него.

64 запроса подряд с паузой ~0,35 с прошли без 429. Параллельную нагрузку не проверял.

## Магазин

Без выбора магазина сервер берёт точку «117042, Москва, Южнобутовская ул, д.97»
(в списке самовывоза её нет, у неё самый большой ассортимент — похоже, склад доставки).
Адрес текущей точки приходит в каждой карточке листинга (`store.storeAddress`), так что
проверить, что `saveStore` сработал, можно прямо по листингу.

Все ручки ниже — `POST /ajax/ajax.php`, тело `multipart/form-data`:

| action | Поля | Ответ |
|---|---|---|
| `getSelfPoints` | — | GeoJSON-фичи, все точки самовывоза: 737 штук (Москва 108, МО 252, СПб 47, дальше ЦФО/СЗФО). `id`, `geometry.coordinates` = **`[lat, lon]` строками**, `properties.balloonContentHeader` («ДИКСИ 77162» — номер магазина), `balloonContentBody` (адрес), `balloonContentFooter` (часы). ~390 KB |
| `getNearestStore` | `lat`, `lon`, `isDelivery` (`true`/`false`) | `{"ID":"1353","ADDRESS":"…"}` или `false`, если точка не в зоне (центр у Кремля, Новосибирск, Краснодар → `false`). Для доставки и самовывоза ID совпадали. Может вернуть точку, которой нет в `getSelfPoints` (Митино → `1665`) |
| `saveStore` | `isDelivery`, `store_id`, `coords` (`"lon,lat"`), `address` | пустое тело, магазин записывается в сессию |
| `isStoreDefined` | — | `{"storeDefined":true/false}` |

`find_stores(lat, lon)` проще всего делать по справочнику из `getSelfPoints`
(один запрос, расстояние считать у себя), а `getNearestStore` держать как запасной путь.

Ассортимент и цены различаются по точкам. Дефолтная точка и три точки Москвы,
категории «Молочные» (`sid=10`) и «Овощи, фрукты» (`sid=37`):

| Точка | Молочные | Овощи-фрукты |
|---|---|---|
| по умолчанию (Южнобутовская 97) | 1235 | 167 |
| 1353 Новокузнецкая 13 | 440 | 90 |
| 1586 Габричевского 10 | 376 | 73 |
| 554 Первомайское (Новая Москва) | 549 | 77 |

Первые 3 страницы по каждой: 95 общих товаров, у 19 (20%) цена различается хотя бы
в одной точке (творог 127,99 / 149,99 / 134,99 / 134,99). Для одной точки режимы
`isDelivery=true` и `false` дают одинаковые цены и ассортимент.

## Эндпоинты

| Что | Запрос |
|---|---|
| Дерево категорий | `GET /ajax/json.php?block=tree` → `{tree:[{name, href, icon, hideAlko, items:[{title, href}]}]}`. Два уровня, **без id**. 25 товарных корней и 332 подкатегории; ещё 6 записей без `name` — промо-подборки брендов и рецепты (O!LIFE, Балтика, Хуторок, `/catalog/retsepty/`), их пропускать. Корень «Скидки по карте» (`sid=839`) — тоже подборка, в ней товары повторяются. Внутри корней есть подкатегории «Наша Марка», где те же товары повторяются |
| id категории | только из HTML страницы категории: `initSectionBehavior({"sid":10,"active_sid":11,…})`, где `active_sid` — id текущей категории, `sid` — id корня. Одна страница — один запрос, 332 подкатегории ≈ 2 минуты. Можно ходить только по 25 корням: листинг корня включает все подкатегории, а id листа есть в карточке (`section_id`) |
| Листинг | `GET /ajax/listing-json.php?block=product-list&sid={id}&perPage=30&page={n}&collect_stat` → `[ {pagenData:{element_count, page, pages_count, page_size, isLastPage}, cards:[…], …} ]`. `perPage` больше 30 (31, 60, 100) → **пустое тело** со статусом 200. Если `page` больше `pages_count`, приходит снова последняя страница, поэтому останавливаться надо по `pages_count`/`isLastPage`. Тело начинается с `\n` — перед `json.loads` делать `strip()` |
| Подкатегории со счётчиками | `GET /ajax/listing-json.php?block=filter-list&sid=…&active_sid=…&filter_title=&gl_filter=` → `[{title, count, items:[{title, href, count}]}]`, id и тут нет. `count` больше `element_count` листинга (731: 2619 против 2073) — видимо, считает и то, чего нет в точке |
| Фасеты | `GET /ajax/listing-json.php?block=facet-list&sid=…&gl_filter=` (цена min/max, торговые марки) |
| Карточка | `GET /product/{slug}-{xml_id}/` — **только HTML**, slug нужен полный, взять его из `url` в листинге (`/product/x-2000216292/` → 404). Цена в карточке тоже зависит от сессии |
| Отзывы | `GET /ajax/reviews-json.php?xml_id=…&page_size=10&page=1&sort=rating&order=desc&stars=null` |

## Поля

Листинг (`cards[]`): `id` (внутренний id Битрикса, по нему корзина), `xml_id`
(артикул 1С, бывает `2000216292`, `DI00078763`, `10E0074360`, `ЦТ0020568`, его же
показывает карточка как «Артикул»), `title`, `url`, `src` и `previews[].src`
(относительные пути `/upload/iblock/…webp`), `brand`, `type`, `section`/`section_id`
(лист), `weight` («294 гр» — похоже, брутто), `rating`.

Цены — **рубли строкой**: `priceSimple` «99.99», `oldPriceSimple` (если скидки нет,
равен `priceSimple`); `price`/`oldPrice` — то же самое с HTML-разметкой. Скидка: `crossPrice:true`,
`badges[]` («-33%», «по акции», «до 31.12.2026», «только самовывоз»).

Наличие: `amount` — остаток в точке (шт или кг, дробный), `canBuy`,
`isEnoughText` («Товар скоро закончится» / «В наличии достаточно»). Позиций с
`amount=0` в листинге не встречалось — видимо, отсутствующие не отдаются.
`status` (`in-time`, `kdd`, `null`) — значение не разобрал.

Весовые: `variant:"весовой"`, `symbol:"кг"`, `priceSimple` — цена **за кг**,
`ratio` — шаг добавления в корзину (0.7 кг у бананов). Штучные:
`variant:"штучный"`, `symbol:"шт"`.

Алкоголь: `isAlko:true`, `hideAlko:true`, но цена приходит.

Карточка (HTML, блок `div.detail-data`):
- «Пищевая ценность в 100 г»: `div.block__wrap` → `span.block__title` (102 / «6 г») + `p.text` (Калории/Белки/Жиры/Углеводы); блок продублирован (mobile);
- `div.detail-data__holder.compound` → «Состав»;
- «Информация»: пары `div.list__line` → `span.text` + значение: Артикул, Торговая марка, Страна, Тип товара, Жирность, **Вес** (в кг, «0.27»), Тип упаковки…;
- «Условия хранения» (срок, температура);
- «Описание».

Ещё в карточке есть JSON-LD `Product` (`name`, `image`, `description`, `brand.name`, `sku` = xml_id,
`offers.price`) и хлебные крошки `schema.org/BreadcrumbList` — по ним можно определить категорию.
Производителя в просмотренной карточке не было.

Образцы ответов: `scratchpad/dixy/sample_listing.json`, `sample_details.html`,
`sample_stores.json`, `sample_nearest.json`.
